# Life Atlas

旅とマンホールカード、土地の学びを地図に残す個人用アプリです。年表機能は含みません。

## GitHub Pagesへの配置

1. GitHubで新しい公開リポジトリを作ります（例：`life-atlas`）。
2. このフォルダ内のアプリファイルをリポジトリの一番上に追加します。
3. Settings → Pages → Sourceで「Deploy from a branch」を選択します。
4. Branchを `main`、フォルダを `/(root)` にしてSaveを押します。
5. Pagesの画面に表示されるVisit siteから開きます。

公式手順：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 記録の保存と移行

アプリの画面とプログラムだけを公開します。実際のタイムライン、バックアップ、写真や個人のメモはリポジトリに追加しないでください。

タイムライン.jsonを選ぶ → 期間を指定 → カード取得・メモを入力 → 「表示中の旅を端末に保存」。

Androidとパソコン間では、編集した端末でバックアップを書き出し、移動先で取り込みます。
取り込みは全体の置き換えです。一方の端末ずつ編集し、切り替える前に書き出してください。
初期版・年表版のバックアップにも対応しています。年表版の追加記録は非表示で保持し、再書き出しに含めます。

保存先は同じ端末・同じブラウザ・同じサイトの端末内ストレージです。ブラウザのデータ削除で消えます。
ローカルHTML版の保存内容はGitHub Pages版に自動では移りません。旧版で書き出し、新しいURLで取り込んでください。
同じ github.io ドメインの他のアプリとも保存領域を共有する場合があるため、自分のアプリ用リポジトリで使ってください。

タイムライン解析と記録の保存はブラウザ内で行い、アップロードやアクセス解析の機能はありません。
地図の背景はOpenStreetMap、地図ライブラリはunpkg、フォントはGoogle Fontsから読み込みます。
外部サービスへの接続は発生し、地図サービスには表示範囲が伝わります。地図表示にはインターネット接続が必要です。

タイムラインの施設名が含まれない場合は「訪問地点」と表示します。始点・終点だけの経路は直線表示です。
Android実機および実際の個人タイムラインファイルでは未検証です。

## マンホールカードの取得候補

全訪問先のメモフォームは表示しません。GKPの全国配布場所一覧の住所を国土地理院住所検索で推定座標へ変換し、訪問地点からの距離で候補を抽出します。座標が一意に得られず、自治体を確認できない住所は除外しています。収録件数は画面で確認できます。

距離は100m、300m、500m、1kmから選べます。カードごとにまとめ、20件ずつ表示します。取得済みを選んだ候補だけ、メモを開けます。取得状態とメモを保存するには「表示中の旅を端末に保存」を押してください。

現在の配布場所と照合するため、過去の配布場所変更は反映できません。発行日前の訪問は候補から除外します。配布時間・在庫・季節別窓口を判定しないため、必ず本人が取得を確認してください。座標は配布場所住所の推定位置であり、マンホールの設置座標ではありません。移動経路だけのデータは照合しません。

GKP配布場所一覧：https://www.gk-p.jp/mhcard/?pref=zenkoku
座標作成：国土地理院 住所検索。地理院地図：https://maps.gsi.go.jp/
カード画像は転載していません。配布場所情報は取得時点のスナップショットです。
